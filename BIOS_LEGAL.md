# BIOS Files - Legal Notice

## ⚠️ IMPORTANT LEGAL INFORMATION ⚠️

**BIOS files are copyrighted software owned by the respective hardware manufacturers.**

### Legal Ways to Obtain BIOS Files:

1. **Extract from hardware you own** - The ONLY legal method
   - You must physically own the console
   - Use homebrew dumping tools
   - Follow guides specific to each system

2. **What is ILLEGAL:**
   - ❌ Downloading BIOS files from the internet
   - ❌ Sharing BIOS files with others
   - ❌ Using BIOS files from consoles you don't own

### System-Specific Dumping Resources:

**PlayStation 1:**
- Use PS1 BIOS dumper disc
- Requires a modded PS1 or swap disc method

**PlayStation 2:**
- Use PS2 BIOS dumper homebrew
- Requires FreeMCBoot memory card

**Sega Saturn:**
- Use Action Replay 4M+ and dumper software
- Can also use Saturn dev tools

**Dreamcast:**
- Use DreamShell or other homebrew
- Requires boot disc capability

**Nintendo DS:**
- Use GodMode9 on a 3DS to dump DS BIOS
- Or use DS firmware dumper tools

**Game Boy Advance:**
- Use GBA BIOS dumper ROM
- Requires flash cart or emulator with ROM boot

### Where BIOS Files Should Be Placed:

```
BIOS/
├── gba_bios.bin          (Optional for GBA)
├── scph5501.bin          (Required for PlayStation)
├── SCPH39001.bin         (Required for PS2)
├── saturn_bios.bin       (Required for Saturn)
├── dc_boot.bin           (Required for Dreamcast)
├── dc_flash.bin          (Required for Dreamcast)
├── bios7.bin             (Required for DS)
├── bios9.bin             (Required for DS)
└── firmware.bin          (Required for DS)
```

### Alternative: Systems That Don't Need BIOS

Many systems work perfectly without any BIOS files:
- ✅ NES, SNES, N64
- ✅ Genesis, Master System, Game Gear
- ✅ Game Boy / Game Boy Color (cores include HLE)
- ✅ Most arcade systems
- ✅ PSP
- ✅ Atari systems
- ✅ PC Engine

**Start with these systems if you don't have BIOS files!**
